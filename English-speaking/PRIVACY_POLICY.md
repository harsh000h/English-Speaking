# English Speaking Privacy Policy

Last updated: 17 September 2026

## What English Speaking does
English Speaking helps users practice spoken English through browser speech features, optional AI feedback, and text-to-speech.

## Microphone
The microphone is activated only after the user taps a speaking button. In free browser mode, audio is processed by the browser speech service and is not stored by this app.

## Data stored locally
The app may store practice preferences and progress in the browser's local storage. Users can export or delete this data from the Free mode & privacy section.

## Optional AI services
If an administrator configures an AI backend, spoken text may be sent to that service to generate feedback. AI API keys are kept on the server and are never placed in the browser. Audio is not intentionally stored by this app.

## Children
The app is an educational tool. Children should use it with a parent, teacher, or guardian's knowledge.

## User choices
Users may use the free browser mode without an account, payment, or API key. Users may clear local data at any time.
