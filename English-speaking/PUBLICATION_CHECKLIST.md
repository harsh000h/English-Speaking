# English Speaking publication checklist

## Completed in this workspace
- Free browser mode
- Mobile-first UI
- Level test and speaking test
- Voice selection and fallback voices
- Local progress and data export/delete
- Optional AI backend
- PWA manifest and offline cache
- JavaScript syntax check
- Duplicate-ID check
- Backend health and chat endpoint checks
- Privacy policy draft

## Required before public launch
- Replace the privacy-policy contact placeholder
- Test Chrome Android microphone permission
- Test Samsung Internet and iOS Safari fallback behavior
- Test an older Android phone and slow network
- Add an Android wrapper such as Capacitor or Flutter
- Configure app icon and splash screen
- Configure notification permissions and reminder scheduling
- Choose a pronunciation provider and add its server credentials
- Add authentication/database only if cloud sync is required
- Add public-server rate limiting and abuse monitoring
- Run accessibility checks with large text and screen readers
- Review AI provider terms, privacy, and regional requirements
- Never commit API keys
