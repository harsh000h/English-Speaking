# English Speaking: free-first plan

English Speaking is designed to be usable without payment from learners and without charging learners.

## Free mode
- Browser Speech Recognition where supported
- Device text-to-speech voices
- LocalStorage progress
- Local level test
- Local repeat-after-me practice
- Demo corrections
- No login
- No audio storage
- No API key required

Best supported browser: Chrome on Android.

## Optional advanced mode
The backend can use OpenAI TTS and AI feedback when an administrator supplies a key. This is optional; the app continues working without it. The key stays on the server and is never exposed to users.

## Keeping it free
- Publish the source code openly
- Do not charge learners
- Do not sell learner data
- Keep audio processing temporary
- Add rate limits if a public server is provided
- Use a community donation or grant only if hosting costs become necessary

## Honest limitation
Unlimited realistic AI voices, cloud pronunciation scoring, cloud accounts, and public hosting all require computing resources. They cannot be guaranteed at zero cost forever. The free browser mode avoids those costs and remains available to everyone.
