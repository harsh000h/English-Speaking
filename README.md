# English Speaking

Free open-source English speaking practice app.

The application files are inside the `English-speaking` folder.

Main app:

[Open English Speaking app](./English-speaking/english-speaking-coach.html)

## Features

- Speaking practice
- Level test
- Daily 10-minute practice
- Conversation topics
- Voice personalities
- Privacy controls
- Local progress
- Free browser mode

## Status

This project is under development.
